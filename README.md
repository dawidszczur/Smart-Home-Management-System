# Smart-Home-Management-System

The objective of this project was to design and implement a smart home system that simulates
the control and monitoring of various smart devices, including lights, thermostats, security
cameras, and door locks. The project emphasizes the use of object-oriented design (OOD)
principles and incorporates two well-established design patterns: the Singleton and Observer
patterns. 

The smart home system was developed to provide extensibility, allowing for the addition of new
device types, and to simulate real-time device monitoring and notifications. The core
functionality includes toggling device states (e.g., turning lights on or off), adjusting settings
(e.g., thermostat temperature), and logging notifications about significant events, such as
security alerts or temperature changes.

The implementation is based on a UML class diagram, which ensures a clear representation of
the system's structure and relationships. The project code was written in C#, using principles
such as encapsulation, inheritance, and polymorphism to maximize code reusability and
maintainability.
